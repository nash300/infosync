# Security policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** button on the repository Security page,
or email `service@screenia.se`. Include the affected page or endpoint, the steps
to reproduce the issue, and the impact you observed. Do not include real customer
data, passwords, API keys, or payment details.

We will acknowledge a report as soon as practical, investigate it privately, and
coordinate a fix before public disclosure.

## Supported version

Only the code currently deployed to `https://screenia.se` is supported with
security updates.
